    Global settings

    Oversized bodies have partial coverage: report mode allows and records; block mode rejects detected attacks (403) or a clean prefix (413). Timeout/capacity/engine errors use the failure policy below.

    Coraza
    CrowdSec AppSec

    AppSec report-only suppresses only this plugin's immediate deny. Remote out-of-band rules can still create IP bans. Use an isolated/non-remediating AppSec configuration for learning. Per-rule exclusions, paranoia and rule details are unavailable.

    Speed

    Same rules, same detection. The plugin frees memory from finished requests in batches; a higher level waits longer between clean-ups: more requests per second for more RAM. Takes effect immediately when saved (not if the plugin was started with GOGC=off).

    Lab values (2-vCPU test machine, 8 runs, October 2026), not a promise for your server. The gain only matters when the plugin is busy; at low traffic every level answers equally fast.

    CPU cores: the plugin automatically uses every core the Zoraxy machine has and checks that many requests in parallel; nothing to configure. More cores raise the maximum requests per second, they do not make a single request faster. The limit for simultaneous checks is Concurrent inspections above.

    Redacted event retention

    Retention changes take effect after plugin restart. Live events are memory-only; JSONL is the optional SIEM feed.

    Change history

    Every saved revision with what changed. Restore makes that revision current again as a new, audited revision. Stored keys are never shown.

    Failure policy

    Default is bypass (fail open). Exact host/route entries below use the opposite policy: with bypass they form a fail-closed list; with fail closed they form a bypass list. No wildcard matching. Off/report mode never fails closed.

    Host overrides

    Use an exact lowercase hostname or Zoraxy route ID; / identifies the default site only (not a path prefix). Other path keys are rejected. Route ID takes precedence. Zero limits inherit the global value.

    Scoped exceptions

    No automatic allowlisting. Review every suggestion. Exceptions apply only to the chosen rule + host + path, optionally method and argument. Expiry is mandatory (maximum 366 days). Existing exceptions are inactive while using an engine without rule exclusions.

    Selected engine does not support local rule exclusions.

    Live WAF events

    Export filtered JSONL

    Newest 200 matching events. Clean allowed requests are counted but not logged. No bodies, passwords or cookie values are stored. Paths/client IPs/User-Agent may still be personal data; restrict access and retention.

    Alerts

    Push a few conditions to your monitoring or chat. Off by default; when off, nothing runs and nothing is sent. Delivery is best effort (5 s timeout, no retries) and never slows inspection.

    Receivers

    json posts the alert as JSON ({v, time, source, key, severity, title, message, fields}) for monitoring systems and automations, optional bearer token. text posts {"text": …} as Mattermost and Slack incoming webhooks expect.

    Learning suggestions

    Use report-only mode for a canary host. These are suggestions from the current filtered event window, not approved exceptions. No request is resent, and no rule is automatically disabled.

    Request phases only · No response-body inspection · Configuration is validated, compiled and persisted before activation.
